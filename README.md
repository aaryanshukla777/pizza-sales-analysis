# Pizza Sales Analysis

This project is a SQL analysis of pizza order data. I used the dataset to look at sales, popular pizza choices, ordering patterns, and delivery performance.

The dataset contains 1,004 orders.

## What I looked at

- Monthly sales and order trends
- Most popular pizza types
- Weekend vs weekday orders
- Peak ordering hours
- Delivery delays
- Topping preferences
- Sales by location
- Traffic levels and their effect on delivery
- Payment methods
- Pizza size preferences
- Delivery efficiency
- Longest delivery times
- Restaurant performance
- Data quality checks

## SQL used

- GROUP BY and aggregate functions
- CASE statements
- Date and time functions
- Subqueries
- CTEs
- Filtering and sorting
- Data quality checks

## Tools

- MySQL
- SQL

## File

`pizza_sales_analysis.sql` contains the SQL queries used for the analysis.
